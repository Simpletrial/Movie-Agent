# 🎬 Movie Agent

Movie Agent is a Python-based practice project developed during my internship to understand agent-style logic, JSON data handling, and clean project structuring.

The project works with movie-related data stored in a JSON file and demonstrates how a simple movie agent can read, process, and manage that data.

## 📁 Project Structure

movie-agent/
├── main.py
├── requirements.txt
├── README.md
├── .gitignore
├── SRC/
│   ├── movie_agent.py
│   └── data/
│       └── movie.json
└── .venv/

## ⚙️ Technologies Used

- Python 3  
- Requests library  
- JSON file handling  

## 🚀 How to Run the Project

Clone the repository and navigate to the project folder:

git clone <your-github-repository-url>  
cd movie-agent  

Install the required dependencies:

pip install -r requirements.txt  

Run the project:

python main.py  

## 📝 Notes

- Movie data is stored in `SRC/data/movie.json`
- Virtual environment files are excluded using `.gitignore`
- This project was created as part of internship practice to strengthen Python fundamentals and project organization
